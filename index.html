Stage 3 · Dark Web (concept)

You hear about .onion

The Dark Web is a tiny slice that is hidden on purpose. Normal Chrome/Safari can’t open it. Addresses often end in .onion and need software like the Tor Browser.

  • Note Not on Google’s results
  • Note Needs Tor (or similar)
  • Note Used for privacy — and sometimes misused
Tor

A quick history The Onion Router

“Onion routing” wraps data in layers of encryption — peeled one relay at a time, just like an onion.

  • 1990sInvented at the U.S. Naval Research Lab to protect intelligence comms.
  • 2002First public release of Tor — “The Onion Router.”
  • 2006The nonprofit Tor Project forms; now used worldwide for privacy.

Wrapped in 3 layers 🧅

Your request is encrypted like an onion — each relay peels just one layer.

Entry peels layer 1 Middle peels layer 2 Exit peels layer 3 → message
🔍 Normal search 1 direct hop ⚡ Fast 👁 Site + ISP see your IP
🧅 Through Tor 3 relay hops 🐢 Slower by design 🛡 No hop sees the full path
